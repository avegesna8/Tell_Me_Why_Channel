Privacy Policy

This policy explains how Tell Me Why Channel Automation accesses, uses, stores, and protects account data.

Application operator

This personal-use application is operated by Abhinn Vegesna for the Tell Me Why educational video channel. Privacy questions and deletion requests can be sent to tellmewhy.contact25@gmail.com.

Data the application accesses

After the channel owner grants consent, the application receives authorization to identify connected channel accounts and upload or publish approved media. Depending on the connected platform, it may receive an account identifier, username, profile information, access and refresh tokens, media identifiers, upload status, visibility options, and processing status for media it submits.

How data is used

Account data is used only to connect the owner's YouTube, Facebook, Instagram, and TikTok accounts; upload owner-approved videos, thumbnails, captions, and metadata; keep test or review uploads private where supported; check processing status; and report resulting links and status to the owner.

Storage and protection

OAuth credentials and publishing tokens are stored locally during setup and as encrypted GitHub Actions secrets for automated operation. Generated media and workflow state are stored in a private Google Cloud Storage bucket. Access is limited to the application operator and service identities required to run the workflow.

Retention

Generated project media is generally deleted from private production storage seven days after successful processing. Small workflow records, including media identifiers and completion status, may be retained to prevent duplicate uploads and support operational history. Authorization credentials are retained until the owner revokes or replaces them.

Sharing

Account data is not sold, rented, used for advertising, or shared with data brokers. It is disclosed only to service providers required to operate the workflow, including Google Cloud, GitHub Actions, email delivery, and the publishing platform selected by the owner, or when required by law. Media-generation providers do not receive social-platform OAuth credentials.

Revocation and deletion

The owner can revoke access through the connected platform's account or business-integration settings. The owner may request deletion of retained application records by emailing the address above. Revocation stops future API access but does not automatically delete media already uploaded to a platform.

Google API Services User Data Policy

The application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including its Limited Use requirements.
